# About-Us-Matrix

一个基于原版增强的Matrix介绍页面
原网页:[Vue App(可能过时)](https://matrix.sysu.edu.cn/about/)

## 主要改进

- 使用PS拆分原网页素材，改善不同分辨率下网站的显示效果。
- 移动端适配。
- 添加动画，页面更动态。
- 支持深色模式。
- 补充了网站字体的选择。
